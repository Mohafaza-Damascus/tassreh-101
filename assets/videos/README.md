# مجلد الفيديوهات التوضيحية

صفحات "مزيد من التفاصيل" تعرض مشغّل فيديو يقرأ من هذا المجلد.
ضع الملفات بالأسماء التالية بصيغة MP4 ليعمل المشغّل:

| الملف | الصفحة |
|---|---|
| `transport-permit.mp4` | `pages/transport-details.html` |
| `rubble-transport.mp4` | `pages/rubble-details.html` |
| `excavation-permit.mp4` | `pages/excavation-details.html` |
| `distributor-permit.mp4` | `pages/distributor-details.html` |

ما دامت الملفات غير موجودة يظهر المشغّل فارغاً دون أن يتعطل باقي الصفحة.
